# Torre de Conciliação Flora × Mandalog

Página estática publicada pelo GitHub Pages. Todo o conteúdo (`index.html` e
`xmls.enc.json`) está **cifrado** (AES-256-GCM, chave derivada da senha por
PBKDF2-SHA256): sem a senha, o que há aqui é texto cifrado. A senha não está
neste repositório.

Gerado a partir de `scripts/flora_torre/` do repositório `mandalog-controladoria`.
Para atualizar, substitua `index.html` e `xmls.enc.json` pelos da nova geração.
